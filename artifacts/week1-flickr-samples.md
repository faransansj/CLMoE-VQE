- 기존 점수 비율(×1, train-IDF CIDEr-D): frozen base F/C 1.634, independent 0.193, expansion(seed 집계) 0.281, G1 validation normalizer 0.224.
- reference 분포: F train/val/eval refs-per-image 평균 5.0/5.0/5.0, C train refs-per-image 평균 5.001 (manifest 내 중복 reference 2건 관찰; 원본 COCO 재대조 미수행).
- whitespace 토큰 평균: C 10.4603/10.4414/10.4444, F 12.3596/12.3969/12.3227 (train/val/eval).
- 전체 512개 최종 F 예측 생성 플래그: eos이고 한도 미도달 316개, limit_reached 196개 (38.3%).
- scorer 정적 검사: metrics.py의 _tokenize/_fixed_cider_score는 모든 cider_d task 공용 단일 구현, IDF는 task train 2,048장 참조만 사용(평가 참조 미포함), C/F scorer lock은 train corpus 내용 해시 2종만 다름.
